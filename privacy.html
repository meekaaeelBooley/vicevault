ViceVault Privacy Policy

Last updated: 22 November 2026

What ViceVault is

ViceVault is a personal application used by its owner to upload video clips to the owner's own YouTube channel.

What access it requests

ViceVault asks for one Google permission: youtube.upload, which allows it to upload videos to the signed-in YouTube channel. It cannot read, edit or delete existing videos, and it cannot see account details such as your email, subscribers or watch history.

What data is stored

A sign-in token is stored in a file on the owner's own computer so uploads can run without signing in each time. It is never sent anywhere except to Google to authorize uploads. ViceVault has no server and no database, and it does not collect, sell, share or analyze personal information.

Google API Services

ViceVault's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

You can revoke ViceVault's access at any time at myaccount.google.com/permissions.
